# 模块注入说明

## 音效增强 `jiafee-fx-v2` 2.2.0

- 资源：`10-sound-effect-runtime.js`、`fx-presets.json`、`mineradio-fx.js`、AudioWorklet。
- 注入：`index.html` 加载 FX runtime，`index-loader.js` 加载音效控制模块，`index.css` 追加独立样式。
- 验证：资源存在、三个增量标记存在、模块加载项唯一。
- 卸载：删除四个资源及自己的三个标记块；保留一起听标记。

## 一起听联机 `jiafee-coplay2` 2.3.0

- 依赖：随补丁注入的 `ws ^8.22.0`；Node 内置 `net`、`http`、`https`、`dns`、`dgram`、`crypto`。
- 后端：`desktop/together-listen/*.js`。
- renderer：`public/js/modules/12-together-listen/*.js`。一起听入口固定在桌面标题栏的 DIY 按钮旁，不进入播放器控制条；保留原有大厅、表单和房间结构。外壳沿用音效 `quality-popover` 的 24px 背景模糊、饱和度、冰灰细边框和双层阴影，并将黑色填充降到 58% 以增强玻璃通透感；滚动能力保留但不显示右侧滚动条。头像连接区退出时先淡出再隐藏，创建/加入大厅与房间视图使用连续的退场和入场动画，且兼容减少动态效果设置。头像连接区与聊天气泡布局保持独立。
- 注入：主进程 import/runtime/IPC/清理，preload bridge，renderer 模块列表、UI、CSS、播放器暂停准备/曲终/seek/Cuefield 适配，以及 package.json 依赖。
- 联机：服务端依据套接字真实来源允许非回环私网地址免码；回环代理、公网和 FRP 入口仍需 6 位授权码。保存地址会先校验、规范化并写入本机配置，且不保存授权码；从远程保存项进入时必须在直连区输入 6 位授权码。聊天输入栏支持 `∧/∨` 收起和展开，状态保存在当前窗口；收到对方消息时播放约 0.2 秒、低音量的柔和提示音。聊天 UI 直接订阅主进程消息事件，重连期间若成员列表尚未恢复会暂存消息，房间状态恢复后补显示，不再因时序差异丢字。文字消息通过独立渲染事件转发，即使重连后房间版本没有变化也能立即更新气泡。文字气泡脱离头像网格独立布局，输入条随气泡高度平滑移动；断线最多重试 3 次，失败后清除连接。连接地址和授权码区仅向本机房主显示。首次连接会清空底部控制条的旧播放信息；离开房间或重连耗尽后会释放一起听媒体、队列和加载状态，恢复正常单人播放，临时重连过程不会提前清理。
- 安全：IPC 复用 Mineradio 的 `isTrustedMainWindowIpc`，操作类型经过白名单，preload 只公开明确方法；免码规则不接受 renderer 自报的网络类型。
- 卸载：恢复 package.json 的模块前备份，删除自身资源和标记，保留音效模块。

## 兼容性边界

清单仅把 2.2.0 标为已测试。主版本 2 且不低于最低版本可进入检查，但任何关键锚点缺失都会阻止写入。旧版 `jiafee-coplay-v2` vendor/signaling payload 保留作历史文件，但不再由新版一起听 manifest 安装。
